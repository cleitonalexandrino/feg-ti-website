## 🚀 Tecnologias Utilizadas

- **React 18** + **Vite 5**: Performance ultrarrápida e renderização fluida.
- **Tailwind CSS**: Estilização moderna com design system escuro corporativo (*Deep Tech Navy* e acentos em azul e laranja).
- **Lucide React**: Biblioteca de ícones vetoriais modernos.
- **Integração WhatsApp**: Gerador automático de mensagens estruturadas para cotação direta no WhatsApp comercial.

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar as dependências (já instaladas nesta pasta)
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev

# 3. Gerar a build de produção (arquivos estáticos na pasta /dist)
npm run build

# 4. Pré-visualizar a build de produção
npm run preview
```
